# note-definitions_PXM

PXM fork of [Note Definitions](https://github.com/dominiclet/obsidian-note-definitions), based on the MIT-licensed original by Dominic Let.

This repository distributes the compiled plugin bundle for personal installation with BRAT.

## Install with BRAT

Add this repository in BRAT:

```text
tmdt5217/note-definitions-pxm
```

Then choose version:

```text
0.36.9-PXM.7
```

## Important

- Do not enable this plugin together with `note-definitions` or `pxm-note-definitions`; all three can register overlapping views and commands.
- The plugin settings file `data.json` is not included. Configure the definition folder after installation.
- Existing definition shards and WeRead notes are not modified by installation.
- This fork includes the original plugin bundle and PXM modifications. See `LICENSE` for copyright and permission notices.
